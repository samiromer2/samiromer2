## Featured projects

**[French in Canada — Analytics](https://github.com/samiromer2/self-french-learning)** · [live dashboard](https://self-french-learning.vercel.app/analytics)
An end-to-end data project on **Statistics Canada** census data (bilingualism and language use across Canada). A Python pipeline (`ingest → clean → validate → insights`) with unit tests, SQL across PostgreSQL and SQLite, Power BI–ready output, and an interactive dashboard (Overview, Geography, Trends). Personal practice metrics and population data are kept deliberately separate — no false comparisons.
*Python · pandas · NumPy · SQL · Recharts · Next.js · Data: Statistics Canada (Open Government Licence)*

**Risk Management Dashboard — Carlington Community Health Centre** *(private repo — available on request)*
An interactive dashboard digitizing a health centre's two real risk instruments: a compliance self-assessment across 13 risk dimensions (~108 criteria) and a live issues-and-risk register.
*React · TypeScript · Firebase*

**[Interactive Data Storytelling](https://github.com/samiromer2/interactive-storytelling-nextjs)**
A scrollytelling feature that turns a dataset into a narrative with interactive visuals.
*Next.js · TypeScript · data visualization*
